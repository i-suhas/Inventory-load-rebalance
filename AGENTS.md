# AGENTS.md — Inventory Rebalancing System V2

## Project Overview

An enterprise-grade AI inventory management platform built on TanStack Start + Netlify. The core value is a multi-model forecasting pipeline that feeds into risk scoring and automated supply-chain recommendations.

## Key Architectural Decisions

### Server Functions vs API Routes
All data logic is exposed via TanStack Server Functions (`createServerFn`) in `inventory.functions.ts`. These are called directly from React components using `useServerFn`. No separate REST API is needed.

### AI Gateway (Netlify)
The TFT-style forecasting model calls Anthropic Claude Haiku via Netlify AI Gateway — zero API key management. XGBoost-style features are computed in TypeScript (lag, rolling mean) for speed and to model the ensemble concept faithfully.

### Ensemble Weighting
`ensemble = 0.4 * xgb + 0.6 * tft` — weighted toward the AI model. XGBoost handles tabular/calendar features; TFT handles temporal context.

### Risk Engine
Formula: `remaining = stock - 7d_forecast`. Safety stock = 3×avg_daily.
- remaining < 0 OR daysRemaining < 3 → CRITICAL
- remaining < safetyStock OR daysRemaining < 7 → HIGH
- remaining < 2×safetyStock OR daysRemaining < 14 → MEDIUM
- else → LOW

### Recommendation Engine
1. Find HIGH/CRITICAL items (deficit = forecast - stock + safety_stock)
2. Search for same-product surplus in other warehouses (stock > 500)
3. If surplus → Transfer; if CRITICAL with no surplus → Emergency Replenishment; else → Procure
4. Transfer quantity capped at 50% of surplus above 300 units (preserves source buffer)

### Database
- Always run `npx drizzle-kit generate` after schema changes — never apply DDL directly
- Use `drizzle-orm@beta` and `drizzle-kit@beta` (Netlify adapter only exists on @beta)
- Migrations output dir MUST be `netlify/database/migrations`

## Coding Conventions

- `.server.ts` = server-only helpers (DB queries); `.functions.ts` = public server functions
- All DB imports use `.js` extension (ESM requirement with TypeScript)
- Dark theme throughout: `bg-gray-950` base, `bg-gray-900` cards
- Recharts for analytics charts; plain SVG for the transfer flow diagram
- Types defined inline in each file for co-location
